## Featured Projects

### [Mahd — AI-Powered Infant Sleep Monitor](https://github.com/ibtihal7alharbi-tech/Computer-vision-project-)


Real-time infant safety system using a dual-model YOLO pipeline (99% & 91% precision) to detect unsafe sleeping positions and send instant alerts to parents via a Flutter mobile app, integrated through a FastAPI backend.

`Computer Vision` `YOLO` `FastAPI` `Flutter` `Python`

---

### [Muafa — AI-Powered Physiotherapy Assistance System](https://github.com/ibtihal7alharbi-tech/Muafa)

AI platform that analyzes physiotherapy movements using MediaPipe pose estimation and a dual-model architecture (GRU & LSTM), with rule-based logic to count reps and score technique in real-time, deployed via FastAPI with a Flutter mobile app.

`MediaPipe` `GRU` `LSTM` `Pose Estimation` `FastAPI` `Flutter`

---

### [Wisada — AI-Powered Sleep Health Prediction System](https://github.com/ibtihal7alharbi-tech/ML-project)


ML platform that predicts sleep disorders and recommends personalized bedtime schedules by analyzing 32 lifestyle features across 100K records, using HistGradientBoosting (94.49% accuracy) and CatBoost models, deployed via FastAPI and Streamlit.

`Machine Learning` `HistGradientBoosting` `CatBoost` `FastAPI` `Streamlit`

---

### [Heart Failure Prediction using SVM](https://github.com/Ramahalharbi/supervised_machine_learning)

Predictive model to detect heart failure risk using Support Vector Machine with RBF kernel, trained on 918 clinical instances from 5 geographic sources. Achieved 93.55% AUC, identifying Oldpeak and age as the most significant clinical predictors.

`SVM` `Scikit-learn` `Python` `Classification` `Healthcare AI`
